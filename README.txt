Thai Learning Web App

ပါဝင်မှု: ဗျည်း ၄၄ လုံး၊ သရများ၊ အသတ်အုပ်စု ၈ မျိုး၊ အသံအမှတ်အသား ၅ မျိုး၊ နေ့စဉ်သုံး ဝေါဟာရ ၁၀၀ ကျော်၊ Thai TTS, Quiz, Lessons, Saved Words, Progress, Mobile UI, PWA အခြေခံ။

စမ်းသပ်ရန် index.html ကို browser ဖြင့်ဖွင့်ပါ။ PWA install/offline အတွက် HTTPS hosting လိုအပ်သည်။ GitHub Pages တွင် ဖိုင်အားလုံးကို repository root သို့တင်ပြီး Settings > Pages > Deploy from a branch > main / root ကိုရွေးပါ။

မှတ်ချက်: မြန်မာအသံထွက်များသည် အနီးစပ်ဆုံးညွှန်ပြချက်သာဖြစ်သည်။ Browser/device တွင် Thai TTS voice ရှိမှ အသံဖတ်နိုင်သည်။
